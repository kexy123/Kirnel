# KirnelOS
A work-in-progress operating system designed by [@kexy123](https://github.com/kexy123) in C and x86 Assembly for Intel architecture. (C++ is nearly being used in this project.)

This project is primarily recreational and for learning the internal workings of major parts of operating systems, so I do not expect this to become a product for actual use, but I am ambitious on the things that I want to create for KirnelOS.
